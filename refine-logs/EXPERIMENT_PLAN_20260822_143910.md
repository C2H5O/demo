# VGGT-to-MASt3R V1 实验计划

**日期**：2026-08-22
**分支**：`vggtomast3r`
**基线**：`origin/feature/distill3r-student@b311d13db39ab6f75499449588b3429350e7a309`

## 科学问题

使用完全冻结、未经微调的 VGGT-Omega base 对每个 RGB frame 独立推理并保存
FP32 camera-local cache。训练时按 metadata 复用并组合这些 cache：当前 student 使用
ordered `(I_t,I_{t+2})` 两帧；公共 reader 同时严格支持 2 帧和 8 帧组合。

独立单帧推理不建立跨帧共享 world/reference gauge，因此本轮只监督每帧各自的
camera-local point map，不构造 `B-in-A` 或融合全局点云。

## 里程碑与运行顺序

1. M0 实现：single-frame generator、版本化 schema、2/8 frame composition、consumer 迁移。
2. M1 Sanity：synthetic/mock contracts、compile、CLI、fresh-agent code review。
3. M2 服务器 smoke：冻结 base teacher 单帧 forward，生成少量真实 cache 并可视化。
4. M3 Dry-run：真实 SCARED/cache 单 batch forward、loss、backward、optimizer。
5. M4 正式实验：完整 train/test frame cache、训练、默认 VDA 与保留的 Endo3R evaluation。

## 固定设置

- SCARED train/test，ordered `(t,t+2)`，pair step 1，不随机换向。
- 448x560，patch 14，token grid 32x40。
- teacher：pretrained VGGT-Omega base，完全 frozen；无 LoRA；单帧独立推理；FP32 cache。
- cache protocol：`frame_local_v1`；旧 pair/clip/LoRA cache 和旧 checkpoint 均拒绝。
- student：官方 `dunemast3r_cvpr25_vitsmall.pth`；DUNE-S/14 frozen；decoder/head trainable。
- student forward：将 `(A,B)` 与 `(B,A)` 合成 `2B`，分别输出 A-local 与 B-local。
- loss：`1.0 * teacher_frame_local_point + 0.1 * reference_SCARED_depth`。
- optimizer：AdamW，lr 1e-4，weight decay 0.05，cosine，5% warmup，grad clip 1.0。
- dataloader batch 2 pairs/GPU（双向解码有效 decoder batch 为 4），AMP auto。

## 预算与执行边界

当前机器缺少真实 SCARED、VGGT-Omega 与联合 student checkpoint，不运行完整 cache 或
长期训练。M2–M4 的真实推理、dry-run、训练和指标须在 GPU 服务器执行。
