# Cross-clip teacher projection 实验计划

**日期**：2026-08-23
**分支**：`feature/crossclip-teacher-projection`
**基线**：`7b61d96`（frozen-base single-frame cache 分支末端）

## 科学问题

测试冻结 VGGT-Omega base 的 16 帧上下文深度能否通过相邻窗口的同帧投影，监督一个
逐帧独立的 DUNE ViT-S/14 + Fast3R DPT point head。训练不使用 SCARED GT，也不使用
photometric/SSIM 或多视图 decoder；真实 SCARED GT 只在 VDA/Endo3R evaluation 中使用。

## 固定方法

- `C_t=[t,...,t+15]`，合法起点 `0..n-16`，窗口 stride 1、序列内随机 shuffle。
- DUNE blocks（0-based）`[2,5,8,11]`，384 dim、12 blocks、patch 14，encoder frozen。
- 只构建 Fast3R `PixelwiseTaskWithDPT`；不构建 Fast3R/MASt3R/LLaMA decoder。
- 左侧：student `C_t[0:15]` 对 teacher `C_(t-1)[1:16]`；右侧：
  student `C_t[1:16]` 对 teacher `C_(t+1)[0:15]`。
- teacher：frozen base、无 LoRA、16 帧推理、FP32 raw cache；尺度只离线审计/对齐，
  aligned cache 写入独立 root；student 不做动态尺度对齐。
- 总损失严格为 `1.0 L_projection + 0.01 L_highlight + 0.1 L_smooth`。
- 默认评估 VDA；显式保留 Endo3R。
