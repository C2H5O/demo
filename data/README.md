# Local data

This directory belongs exclusively to `vggtomega_lora_distill`. Do not point
the project at mutable data directories inside the earlier reference projects.

Expected layout:

```text
data/
  SCARED/          # user-provided SCARED dataset root
  teacher_cache/   # generated by generate_teacher_cache.py
```

Dataset and cache contents are intentionally excluded from Git. Keep this
README so a fresh clone preserves the directory contract.
